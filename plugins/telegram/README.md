# Telegram

Talk to your Claude · Echo folder session from your phone through your own Telegram bot, while the session is open in Echo.
Echo, and plugins such as Scheduler, send to you there. Set it up in Settings → From plugins → Telegram; Claude in Echo
is told what the bot is for and where you manage it. Needs Echo 0.9.9 or later.

Part of the [Echo plugins](../../README.md) marketplace.
